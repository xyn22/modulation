Lesson 3: Putting the message onto the carrier (AM)

In lesson 2 the carrier always had the same height. Now we let the message control that height. This is AM, amplitude modulation: "amplitude" because we change the carrier's height, "modulation" because we change it on purpose to carry information.

1. The message

2. The carrier, before modulation (constant height)

3. The AM signal: the carrier's height now follows the message

What is happening

Compare plot 1 and plot 3 at the same moment in time:

  1. When the message is at its highest point, the carrier in plot 3 is at its tallest.
  2. When the message is at its lowest point, the carrier is at its shortest.
  3. In between, the carrier's height smoothly follows the message up and down.

The carrier still wiggles at its own fast frequency. Only its height changes. Draw a line along the tops of the peaks and you get the envelope, which has exactly the same shape as the message. The message is now "riding" on the carrier.

Modulation depth

Depth says how strongly the message pushes the carrier's height around. The carrier's normal height is 1:

  • 0%: the message has no effect. You are back to the plain carrier from lesson 2, which carries no information.
  • 50%: the height swings between 0.5 and 1.5, half its normal size in each direction.
  • 100%: the height swings between 0 and 2. At the message's lowest point the carrier shrinks to nothing for a moment.

More depth makes the message easier for a receiver to pick out. Lesson 4 shows what happens if you push it past 100%.

Building the formula, one step at a time

Lesson 1 said a wave is "height × sin(2π · f · t)". AM just makes the height change over time.

carrier = 1 · sin(2π · fc · t)  fixed height 1
height(t) = 1 + depth · sin(2π · fm · t)  normal height, pushed up and down by the message
AM signal = height(t) · sin(2π · fc · t)

That is all AM is: multiply the fast carrier by a height that follows the slow message. Here fc is the carrier frequency, fm is the message frequency, and depth is written as a number from 0 to 1 (so 50% = 0.5). In textbooks depth is usually called the modulation index and written as the Greek letter μ ("mu").

Try this
  1. Set the depth to 0%. Plot 3 looks exactly like plot 2: no message is being sent.
  2. Slowly raise the depth to 100% and watch the envelope grow until its lowest points touch the middle line.
  3. Change the message frequency. The envelope changes with it, but the fast wiggles inside stay the same.
  4. Lower the carrier frequency to 10 Hz. With so few wiggles, the envelope becomes hard to see. This is why the carrier must be much faster than the message.

The math

1. The standard form

Textbooks write AM with cosines (lesson 1: same wave, different phase) and a carrier amplitude \(A_c\): \[ s(t) = A_c\,\big[\,1 + \mu\, m(t)\,\big]\cos(2\pi f_c t), \qquad |m(t)| \le 1. \]

  • \(m(t)\) is the message, normalised so its peaks are at \(\pm 1\). Any real audio signal can be scaled this way.
  • \(\mu\) is the modulation index (the depth slider, as a number: 50% means \(\mu = 0.5\)).
  • For a single tone \(m(t) = \cos(2\pi f_m t)\). Sometimes this is written with the message amplitude: \(A_c + A_m\cos(2\pi f_m t)\) gives \(\mu = A_m / A_c\).

2. Why the envelope is an exact copy of the message

Write \(a(t) = A_c[1 + \mu m(t)]\), so \(s(t) = a(t)\cos(2\pi f_c t)\). Because \(f_c \gg f_m\) (lesson 2), \(a(t)\) is almost constant over each carrier cycle, and within that cycle \(\cos\) swings between \(+1\) and \(-1\). So the peaks of \(s\) trace \(\pm|a(t)|\): the envelope is \(|a(t)|\).

If \(\mu \le 1\), then \(1 + \mu m(t) \ge 1 - \mu \ge 0\), the absolute value does nothing, and \[ \text{envelope}(t) = A_c + A_c\,\mu\, m(t). \] That is the message, scaled by \(A_c\mu\) and shifted up by a constant \(A_c\). A receiver that traces the envelope and removes the constant gets the message back. If \(\mu > 1\), \(1 + \mu m(t)\) goes negative at times, the absolute value folds it, and the envelope is no longer a copy of the message. That is over-modulation, covered in lesson 4.

3. Measuring \(\mu\) from the waveform

For a tone, the envelope's largest and smallest values are \(E_{max} = A_c(1 + \mu)\) and \(E_{min} = A_c(1 - \mu)\). Subtract and add: \[ E_{max} - E_{min} = 2A_c\mu, \qquad E_{max} + E_{min} = 2A_c \quad\Longrightarrow\quad \mu = \frac{E_{max} - E_{min}}{E_{max} + E_{min}}. \] \(A_c\) cancels, so you can measure the depth of any AM signal on an oscilloscope without knowing how strong the carrier is. You will implement exactly this below.

4. Why the "1 +"?

Drop the 1 and you get \(s(t) = A_c\,\mu\, m(t)\cos(2\pi f_c t)\): just the message times the carrier. Its envelope is \(|m(t)|\), which folds every negative half of the message upwards, so tracing the envelope no longer recovers the message. The "1 +" is a constant added to the message, which lifts it above zero so the envelope stays faithful. The price: that constant is a pure carrier that carries no information but uses power. Later lessons quantify this cost and show the schemes that avoid it (DSB-SC and SSB), which need smarter receivers.

5. A teaser: what frequencies are in \(s(t)\)?

Expand the tone case: \(s(t) = A_c\cos(2\pi f_c t) + A_c\mu\cos(2\pi f_m t)\cos(2\pi f_c t)\). The second term is a product of two cosines. Lesson 4 uses the product-to-sum identity \[ \cos a\cos b = \tfrac12\big[\cos(a - b) + \cos(a + b)\big] \] to show that \(s(t)\) is really just three pure tones: \(f_c\), \(f_c - f_m\) and \(f_c + f_m\). Try deriving it yourself first: it is a two-line calculation.

  2. Implement estimate_modulation_index(signal, fc, fs), a crude envelope detector:
    • Cut the signal into chunks one carrier period long (\(f_s / f_c\) samples).
    • The peak of \(|s|\) in each chunk is one envelope sample.
    • Apply \(\mu = (E_{max} - E_{min})/(E_{max} + E_{min})\).
    Hint: reshape(-1, period) then max(axis=1) does the chunking without a loop.
  3. Check: pytest tests/test_lesson03.py.
  4. Run python -m examples.lesson03_am. It writes lesson03_am.wav: a 6 kHz carrier whose loudness pulses 150 times a second. Listen for the pulsing: that is the envelope. It also plots the signal with its envelope and prints your estimate of \(\mu\).
Show solution 
def am_modulate(message, fc, fs, mu, carrier_amplitude=1.0):
    t = np.arange(len(message)) / fs
    return carrier_amplitude * (1 + mu * np.asarray(message)) * np.cos(2 * np.pi * fc * t)


def estimate_modulation_index(signal, fc, fs):
    period = int(round(fs / fc))
    usable = len(signal) // period * period
    chunks = np.abs(signal[:usable]).reshape(-1, period)
    envelope = chunks.max(axis=1)
    e_max, e_min = envelope.max(), envelope.min()
    return (e_max - e_min) / (e_max + e_min)

This envelope detector is crude: if \(f_s / f_c\) is not a whole number, or there are few samples per carrier cycle, it misses the true peaks slightly. A later lesson builds a proper one.
