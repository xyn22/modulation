# modulation

Live site: https://xyn22.github.io/modulation/ (redeploys automatically on every push to `main`).

1. [Lesson 1: What is a wave?](01-wave.html) — amplitude, frequency, period
2. [Lesson 2: A slow wave and a fast wave](02-message-and-carrier.html) — the message and the carrier
3. [Lesson 3: Putting the message onto the carrier (AM)](03-amplitude-modulation.html) — envelope, modulation depth, the AM formula

Advanced preview: [AM explorer](am.html) — the full AM formula, envelope and spectrum.
