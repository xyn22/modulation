# modulation

Interactive lessons on signals and AM modulation: the intuition, the math (trig, calculus, and later Fourier analysis), and code. Open any lesson in a browser; no install needed.

Live site: https://xyn22.github.io/modulation/ (redeploys automatically on every push to `main`).

## Lessons

1. [Lesson 1: What is a wave?](01-wave.html) — amplitude, frequency, phase, radians, ω = 2πf
2. [Lesson 2: A slow wave and a fast wave](02-message-and-carrier.html) — message and carrier, wavelength and antennas
3. [Lesson 3: Putting the message onto the carrier (AM)](03-amplitude-modulation.html) — envelope, modulation index, the AM formula

Advanced preview: [AM explorer](am.html) — the full AM formula, envelope and spectrum.

## Project: a software AM radio in Python

Each lesson ends with a coding exercise that adds one piece to a software AM radio, checked by tests. See [`project/README.md`](project/README.md) for setup and milestones.
